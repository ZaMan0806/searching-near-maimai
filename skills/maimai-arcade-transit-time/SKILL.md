# 마이마이 오락실 대중교통 소요시간 조회

사용자가 "OO에서 마이마이 오락실까지 얼마나 걸려?" 같은 요청을 하면, 아래 목록에서 **출발지와 같은 권역의 오락실만** 골라 카카오맵 대중교통 길찾기로 최소 소요시간을 조회한다.

## 1. 권역 필터 (가장 중요)

출발지가 속한 권역의 오락실만 조회한다. 다른 권역(예: 서울 출발인데 광주·부산)은 길찾기를 하지 않는다. 사용자가 특정 오락실이나 권역을 직접 지정하면 그것만 조회한다.

- **수도권**: 서울(강북), 서울(강남), 경기(북부), 경기(남부), 인천
- **충청권**: 대전, 충남 (천안은 수도권 남부 출발이면 사용자가 원할 때만 포함)
- **호남권**: 전남광주, 전북
- **영남권**: 대구, 경북, 부산, 경남

## 3. 조회 방법

- 네이버 지도는 내장 브라우저에서 차단돼 있으니 처음부터 **카카오맵**(`https://map.kakao.com`)을 쓴다. 지도 API 요청을 가로채거나 직접 호출하지 말고 화면 UI만 사용한다.
- 출발지는 길찾기 탭의 "출발지 입력"에 넣고, 자동완성 목록에서 맞는 항목을 클릭한다.
- 도착지는 위 목록의 **길찾기 검색어**를 "도착지 입력"에 넣고 Enter를 누른다. 첫 번째 결과의 등록명과 주소가 목록과 같은지 확인한다.
- 대중교통 탭(두 번째 탭)을 누르고, 결과 목록에서 가장 짧은 시간을 최소 소요시간으로 쓴다.
- 권역 내 오락실은 브라우저 스크립트 하나에서 반복문으로 한꺼번에 돌린다. 한 곳에 4~5초 정도 걸린다.
- 기다릴 때는 `getByText("검색결과").filter({visible:true})`처럼 보이는 요소만 기다린다. 숨은 요소를 기다리면 타임아웃이 난다.
- 시간 파싱: 결과 텍스트에서 `N시간 M분` 또는 `M분` 줄 바로 다음 줄이 `도보`로 시작하는 줄을 경로 하나로 본다.

## 4. 출력 형식

표 말고, 아래처럼 `-` 목록으로 간단히 나열한다.

```
- 부천 P2존 : 1시간 2분
- 잠실 뿅뿅오락실 : 13분
```

이름은 나무위키 이름을 쓴다. 끝에 한 줄로 기준을 적는다(카카오맵 기준, 조회 시각). 추정 매칭인 곳에서 결과를 냈으면 짧게 표시한다.
