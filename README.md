# searching-near-maimai

출발지에서 가까운 **마이마이(maimai DX) 보유 오락실**까지 대중교통 최소 소요시간을 알려주는 Claude 스킬입니다.

- 출발지와 **같은 권역**(수도권 / 충청권 / 호남권 / 영남권)의 오락실만 길찾기합니다. 서울에서 출발하면 부산·광주는 조회하지 않습니다.
- 전국 38곳의 카카오맵 등록명, 주소, 장소 ID, 검색어가 미리 정리되어 있어서 재검색 없이 바로 찾습니다.
- 결과는 이렇게 나옵니다.

```
- 잠실 뿅뿅오락실 : 13분
- 건대 펀시티 : 24분
- 부천 P2존 : 1시간 2분
```

## 사용 예시

> 삼성역에서 마이마이 오락실까지 얼마나 걸려?

> 대전역 근처 마이마이 오락실 시간 알려줘

## 설치

### Claude Code (플러그인 마켓플레이스)

```
/plugin marketplace add ZaMan0806/searching-near-maimai
/plugin install searching-near-maimai@searching-near-maimai
```

### Claude Code (직접 복사)

`skills/maimai-arcade-transit-time` 폴더를 `~/.claude/skills/` 아래에 복사합니다.

### Claude 앱 (claude.ai / 데스크톱)

`skills/maimai-arcade-transit-time` 폴더를 zip으로 압축한 뒤, 설정의 스킬 메뉴에서 업로드합니다.

## 필요한 것

이 스킬은 카카오맵 웹페이지를 브라우저로 조작해 소요시간을 확인합니다. Claude 데스크톱 앱의 **내장 브라우저**나 **Claude in Chrome**처럼 브라우저를 다룰 수 있는 환경이 필요합니다. 브라우저가 없으면 오락실 목록과 주소만 안내할 수 있습니다.

## 데이터 기준과 주의사항

- 오락실 목록과 DX 대수는 **2026년 7월** 나무위키 「maimai DX」 문서의 보유 오락실 표 기준입니다. 이후 폐업, 이전, 대수 변경이 있을 수 있습니다.
- 주소와 장소 ID는 2026년 11월 카카오맵에서 확인했습니다.
- 다음 곳은 카카오맵 등록명이 달라 추정으로 매칭했습니다: 부평 짱구게임장, 순천 그린피아 게임센터, 경성대 게임D 2호점(후보 2곳).
- 소요시간은 카카오맵 대중교통 길찾기 결과이며, 조회 시각에 따라 달라집니다.
